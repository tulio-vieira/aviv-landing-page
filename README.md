# aviv SDG Editorial — landing page

Landing page for **aviv SDG Editorial**, a Christian publishing house in Brasília: https://aviveditorial.com.br

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export to ./out
npm run lint
```

Full documentation (architecture, asset pipeline, Google Analytics, AWS infrastructure and prod deploy) is in [CLAUDE.md](CLAUDE.md).
